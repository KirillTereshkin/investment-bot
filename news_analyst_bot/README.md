# 📈 News Analyst Bot — новостной аналитик российского рынка

Telegram-бот, который по расписанию собирает экономические новости российского рынка из RSS,
прогоняет их через DeepSeek (OpenAI-совместимый API) и присылает краткий торговый прогноз:
резюме рынка, 1–4 идеи с горизонтом и триггером отмены, а также «урок дня».

## Как это работает

```
APScheduler (10,12,14,16,18,20 МСК)
        │
        ▼
news/collector.py  →  6 RSS-источников (независимо, с ретраями)
        │                • RBC News (rssexport.rbc.ru)
        │                • CBR (cbr.ru/rss/RssNews)
        │                • TASS, Interfax, Kommersant, Investing.com
        ▼
news/dedup.py      →  SHA1(нормализованный заголовок) + Jaccard > 0.8
        ▼
collector.build_digest()  →  до 25 строк, round-robin по источникам
        ▼
ai/client.py       →  DeepSeek (JSON-ответ, 2 ретрая, temperature 0.3)
        ▼
storage/db.py      →  SQLite: прогон, статусы источников, сырой ответ, идеи
        ▼
bot/notifier.py    →  Telegram (HTML, разбивка по 3900 символов)
```

Ключевые свойства:

* падение одного источника не роняет прогон — статус каждого источника попадает в сообщение;
* анализ всегда один: `/now` во время планового прогона получит ответ «уже выполняется»;
* если новостей за окно нет — DeepSeek не вызывается (экономия токенов);
* любой ответ модели экранируется (`html.escape`), разметка Telegram безопасна;
* при отклонении HTML-разметки Telegram сообщение автоматически переотправляется плоским текстом.

## Установка

```powershell
cd c:\Projects\investment-bot\news_analyst_bot

python -m venv .venv
.\.venv\Scripts\Activate.ps1

pip install -r requirements.txt
```

> Если PowerShell блокирует `Activate.ps1` («выполнение сценариев отключено»), выполните
> `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` в текущем окне
> или используйте `.\\.venv\\Scripts\\python.exe` напрямую, без активации.

## Настройка .env

```powershell
Copy-Item .env.example .env
notepad .env
```

| Переменная           | Обязательна | Где взять |
|----------------------|-------------|-----------|
| `TELEGRAM_BOT_TOKEN` | да          | [@BotFather](https://t.me/BotFather) → `/newbot` |
| `TELEGRAM_CHAT_ID`   | да          | напишите боту, затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите `chat.id` (для личных сообщений — ваш user id) |
| `DEEPSEEK_API_KEY`   | да          | https://platform.deepseek.com/api_keys |

Без этих трёх переменных `main.py` не стартует и печатает, чего именно не хватает.

## Запуск

```powershell
# из папки news_analyst_bot, с активированным .venv
.\\.venv\\Scripts\\python.exe main.py
```

Ожидаемый вывод:

```
2026-10-15 13:20:01 | INFO     | news_analyst_bot | Расписание: 10, 12, 14, 16, 18, 20 МСК. Следующий анализ в 14:00 МСК
```

После старта бот присылает владельцу сообщение «🤖 Бот запущен. …».

## Команды

| Команда     | Что делает |
|-------------|------------|
| `/start`    | приветствие + расписание |
| `/now`      | анализ немедленно, вне расписания |
| `/last`     | последний прогон из SQLite (статусы источников, дайджест, идеи) |
| `/stats`    | статистика за 7 дней: прогоны, идеи, ошибки DeepSeek, падения источников |
| `/schedule` | расписание и время следующего запуска |
| `/help`     | список команд |

## Проверка перед запуском

В проекте есть смоук-тест из 86 проверок (`_smoke_test.py`) — от дедупликации и парсинга RSS
до полного `run_analysis` с заглушкой бота:

```powershell
.\\.venv\\Scripts\\python.exe _smoke_test.py
```

Особенности:

* Telegram и DeepSeek из теста **не вызываются**: используется поддельная `Bot` с мок-сессией;
* БД теста изолирована — `_smoke.sqlite3`, рабочий `news_bot.sqlite3` не трогается;
* секция `live` реально ходит в RSS-источники, поэтому нужен интернет;
* если в `.env` заполнен `DEEPSEEK_API_KEY`, сквозной тест сделает **один реальный запрос** к DeepSeek — уберите ключ, если не хотите тратить токены.

Ожидаемый финал: `Выполнено проверок: 86` и `ВСЕ ПРОВЕРКИ ПРОЙДЕНЫ`, код выхода `0`
(при `ПРОВАЛЕНО ПРОВЕРОК` код выхода `1`).
Если консоль в cp1251 и тест падает на юникоде — запускайте командой `chcp 65001` перед стартом.

## Структура проекта

```
news_analyst_bot/
├─ main.py              точка входа: логирование, БД, bot, scheduler, polling
├─ config.py            все настройки и секреты (.env), хелперы времени МСК
├─ requirements.txt     aiogram, openai, feedparser, APScheduler, requests, python-dotenv
├─ .env.example         образец переменных окружения
├─ _smoke_test.py       смоук-тест (86 проверок), запускается вручную
├─ ai/
│  ├─ prompts.py        системный промпт и сборка пользовательского запроса
│  └─ client.py         DeepSeek: JSON-режим, ретраи, парсинг ответа
├─ news/
│  ├─ collector.py      RSS-источники, ретраи, окно сбора, дайджест
│  └─ dedup.py          нормализация заголовков, SHA1, Jaccard
├─ bot/
│  ├─ notifier.py       формат сообщений и безопасная отправка
│  └─ handlers.py       /start /now /last /stats /schedule /help
├─ scheduler/
│  └─ jobs.py           CronTrigger, run_analysis, get_market_snapshot
└─ storage/
   └─ db.py             SQLite: runs, индексы, агрегаты для /stats
```
